# 🚢 Titanic Survival Analysis – Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on the famous Titanic passenger dataset using Python and Pandas. The objective is to explore passenger information, clean missing data, identify patterns, and understand which passenger groups had higher survival rates.

## 🎯 Objectives
- Load and inspect the Titanic dataset.
- Perform data cleaning and handle missing values.
- Identify and check duplicate records.
- Analyze survival rates based on gender, passenger class, and age groups.
- Generate meaningful insights using statistical analysis and visualizations.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook

## 📊 Analysis Performed
1. **Gender Analysis:** Compared survival rates between male and female passengers.
2. **Passenger Class Analysis:** Examined survival rates across first, second, and third classes.
3. **Age Group Analysis:** Compared survival rates among children, teenagers, adults, middle-aged and senior passengers.

## 🧹 Data Cleaning
- Identified missing values using Pandas.
- Filled missing age values using the median of passenger class and gender groups.
- Filled missing embarkation values using the mode.
- Removed the deck column because it contained a large proportion of missing values.
- Checked duplicate records and data types.

## 📈 Key Learnings
- Understanding and manipulating DataFrames using Pandas.
- Handling missing values and performing data cleaning.
- Applying grouping and aggregation techniques.
- Creating visualizations to communicate findings.
- Converting statistical results into meaningful insights.
